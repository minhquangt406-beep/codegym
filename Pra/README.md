# Pra - Phối màu đơn tông

## Bản thực hành chính
Bản này được phối lại theo yêu cầu bài:
- Bậc 1: #00ADEE
- Bậc 2: #00B2EF
- Bậc 4: #00BFF2
- Bậc 7: #8DD7F7
- Bậc 9: #C6E9FA

Các phần đã thay đổi:
- Banner/nền nổi bật: #00BFF2
- ON SALE/PREVIEW: #00ADEE / #00B2EF
- Nội dung PREVIEW: #8DD7F7
- Footer/khối thông tin: #C6E9FA
- Màu chữ được điều chỉnh để bảo đảm độ tương phản.

## Chạy bài
Mở `index.html` bằng trình duyệt.

## Nộp GitHub
Upload toàn bộ thư mục `Pra` lên repository GitHub và lấy link repository để nộp.
